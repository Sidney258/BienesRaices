# Website de Bienes Raices

Uma plataforma web de Bienes Raices onde usuarios podem descobrir, publicar e gerenciar propriedades como casas, apartamentos, terrenos e outros tipos de imoveis.

O sistema permite que usuarios criem uma conta, façam login e publiquem seus próprios imóveis, além de gerenciar suas listagens diretamente pela plataforma.

## Funcionalidades

- Registo de usuários
- Sistema de login e autenticação
- Publicação de imoveis
- Edição e exclusão de propriedades
- Listagem de imoveis disponíveis
- Cada usuario pode gerenciar seus proprios anuncios

## Tecnologias Utilizadas

Este projeto foi desenvolvido com as seguintes tecnologias:

- Backend: PHP Laravel  
- Frontend: HTML5 e Tailwind CSS  
- Banco de Dados: MYSQL 
- Interatividade: ALPINE JS

## Sistema de Usuarios

- Criacao de contas
- login
- logout
- Cada usuário pode publicar e gerenciar seus proprios imoveis

## Gestao de Imoveis

Usuários podem:

- Publicar novos imóveis
- Editar propriedades existentes
- Remover imóveis
- Visualizar todos os imóveis disponíveis na plataforma
